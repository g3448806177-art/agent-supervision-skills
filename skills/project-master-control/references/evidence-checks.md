# 专项证据检查

仅按当前任务涉及的对象使用，不对无关任务增加检查。

## 数据与接口

- 缺失数据沿请求、原始返回、解析、合并、保存、计算、展示定位，区分已证原因、候选原因与证据缺口，再安排最小修复；不因页面空值就重新取数。
- 指标明确对象、分母、时间、单位、去重和字段含义；缺失、未知、有效零值分开，相似字段不自动等价，数值不同也不自动证明结果不可用。

## 额度与费用

- 分开记录对象数、请求数、失败重试和实际扣费；报价、估算、回执和账单不混称。没有扣费依据时标未核实，失败不自动增加重试或费用预算。
- 节省对象处理量、调用次数和实际费用分别举证，不由其中一项推定其他项。

## 软件交付

- 按适用仓库流程形成提交/PR，验证结果对应最终提交，发布时核对生产版本与已验收内容。
- 开发完成、测试通过、已合并和已上线分别记录；未运行、跳过及覆盖边界明确说明，不使用旧版本成功结果替代当前验证。
